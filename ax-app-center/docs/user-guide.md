# AX 앱 센터 이용 안내 (직원용)

AI 코딩 도구 등으로 **직접 만든 업무 프로그램**(웹앱, 스크립트, 엑셀 매크로, RPA 등)을 등록하는 곳입니다. 등록하면 위험 등급에 따라 검토를 거쳐 전 법인이 함께 볼 수 있는 카탈로그에 올라갑니다.

**주소**: `https://<tenant>.sharepoint.com/sites/ax-app-center` · **문의**: GBI팀 (사이트 홈 아래 문의처)

## 등록하기

1. 사이트 홈에서 **프로그램 등록하기**를 누릅니다.
2. 양식을 채웁니다. 5분이면 됩니다.
   - **실제 업무 데이터, 계정, 비밀번호, API 키는 적지 않습니다.** "다루는 데이터 설명"에는 종류만 적습니다 (예: "오더 번호, 납기일").
   - "사용 범위", "내부 업무 데이터 사용", "개인정보·단가·재무 데이터 사용", "ERP·MES에 데이터 입력"은 사실대로 답합니다. 이 답으로 등급이 정해집니다.
3. 제출하면 등급에 따라 처리됩니다.

| 등급 | 언제 | 처리 |
|---|---|---|
| **A** | 나만 쓰고, 내부 업무 데이터와 민감 데이터를 쓰지 않음 | 바로 승인. 완료 메일이 옵니다 |
| **B** | 팀·법인이 함께 쓰거나, 오더·생산 같은 내부 데이터를 씀 | GBI팀 검토 (약 5영업일) |
| **C** | 개인정보·단가·재무 데이터를 쓰거나, ERP·MES에 입력하거나, 여러 법인이 함께 씀 | 정보보안 → 시스템 담당 → GBI팀 순서로 검토 |

결과(승인/반려)는 메일로 알려 드립니다. 검토 의견은 등록부의 **내 프로그램** 보기에서도 볼 수 있습니다.

## 바꾸기·그만 쓰기

등록부는 직접 고칠 수 없습니다. 홈의 **변경 신청하기**로 알려 주세요.

- **등록번호**: 등록부 **내 프로그램** 또는 **카탈로그** 보기의 `ID` 값
- **유형**: 정보 변경 / 담당자 변경 / 등급 재판정 / 사용 중단 / 폐기
- 사용 범위나 데이터가 바뀌어 위험이 커지면 **등급 재판정**을 신청합니다.
- 만든 사람이 부서를 옮기거나 퇴사하면 **담당자 변경**을 신청합니다.

## 정기 점검

승인된 프로그램은 12개월마다 점검 요청 메일이 옵니다. 그대로 쓰면 "변경 없음"으로 회신하고, 바뀐 점이 있으면 변경 신청을 합니다.

## 다른 사람이 만든 프로그램 찾기

홈의 **카탈로그**에 승인된 프로그램이 모두 나옵니다. 쓰고 싶은 프로그램이 있으면 **만든 사람**에게 연락합니다.

## 꼭 지킬 것 (임시 보안 수칙)

- 계정, 비밀번호, API 키를 코드나 파일에 직접 적지 않습니다.
- 개인정보·단가·재무 데이터를 외부 AI 도구에 붙여 넣지 않습니다.
- ERP·MES에 입력하는 프로그램은 C등급 승인 전에 운영 시스템에 연결하지 않습니다.
- 승인 전에는 회사 데이터를 외부 클라우드에 올리지 않습니다.
- 코드와 파일은 회사 저장소에 두고 위치를 등록 양식의 "코드·파일 위치"에 적습니다.

자세한 기준: 사이트의 **등급 기준과 절차** 페이지
