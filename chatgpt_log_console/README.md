# ChatGPT 대화내용 월간 자동 수집·분석

매달 **말일**에 `대화내용_받기.BAT` 를 자동으로 실행하고, 내려받아진 로그를 분석해
**HTML 리포트**(`reports\chatgpt_usage_YYYY-MM.html`)까지 만들어 두는 자동화입니다.

```
[매일 09:00] 작업 스케줄러
      │
      ├─ 오늘이 말일인가?  아니면 그냥 종료 (지난달을 놓쳤으면 그때 보충 실행)
      │
      ├─ 대화내용_받기.BAT 실행 ──────→ logs\download_*.log
      │
      ├─ 새로 받아진 파일 탐지 (.sqlite / .json / .jsonl / .csv / .zip)
      │
      └─ 분석 → reports\chatgpt_usage_2026-09.html
```

---

## 1. 설치 (한 번만)

1. 이 폴더의 파일 전부를 `C:\Users\travislee\Downloads\chatgpt_log_console` 에 복사합니다.
   (`대화내용_받기.BAT` 가 이미 있는 그 폴더입니다. 덮어쓰지 않고 나란히 놓으면 됩니다.)
2. **`월간자동화-설치.bat`** 을 더블클릭합니다. 관리자 권한은 필요 없습니다.
3. "작업이 등록되었습니다" 와 다음 실행 예정 시각이 보이면 끝입니다.

> 한글 파일명이 깨져 보이는 환경이면 같은 내용의 `INSTALL.bat` 을 쓰세요.
> (`UNINSTALL.bat` = 해제, `RUN-NOW.bat` = 지금 실행, `ANALYZE-ONLY.bat` = 분석만)

### 필요한 것

| 항목 | 설명 |
|---|---|
| Windows 10/11 | 작업 스케줄러 사용 |
| Python 3.8 이상 | 분석 스크립트 실행용. 설치할 때 **Add python.exe to PATH** 체크 |
| 추가 패키지 | **없음** (표준 라이브러리만 사용, 사내망에서 pip 설치 불필요) |

설치 스크립트가 파이썬을 찾지 못하면 경고를 띄웁니다. 이미 설치되어 있는데 인식이 안 되면
`settings.json` 의 `pythonExe` 에 `python.exe` 전체 경로를 적어 주세요.

## 2. 언제 어떻게 돌아가나

작업 스케줄러에는 **매일 09:00** 으로 등록되지만, 실제 수집·분석은 **말일에만** 합니다.
(28·30·31일이 달마다 달라도 스크립트가 직접 계산합니다.)

- 말일에 PC 가 꺼져 있었거나 로그인하지 않았다면 → **다음에 켰을 때 지난달분을 자동으로 보충**합니다.
- 같은 달을 두 번 분석하지 않습니다. (`.state\state.json` 에 처리한 달을 기록)
- 실행 기록은 `logs\run_*.log`, 받기 출력은 `logs\download_*.log` 에 남습니다.

수동으로 돌리고 싶을 때:

| 파일 | 하는 일 |
|---|---|
| `지금-수집분석.bat` | 말일이 아니어도 지금 받기 + 분석하고 리포트를 띄웁니다 |
| `분석만-다시.bat` | 받기는 건너뛰고, 이미 있는 파일만 다시 분석합니다 |
| `월간자동화-해제.bat` | 스케줄 등록만 지웁니다 (받은 로그·리포트는 그대로) |

특정 달만 다시 뽑고 싶으면 PowerShell 에서:

```powershell
cd "C:\Users\travislee\Downloads\chatgpt_log_console"
powershell -ExecutionPolicy Bypass -File scripts\run_monthly.ps1 -SkipDownload -Force -Period 2026-08 -OpenReport
```

## 3. 리포트에 담기는 내용

`reports\chatgpt_usage_YYYY-MM.html` — 브라우저로 열면 되는 파일 하나입니다. (인터넷 연결 불필요)

- **KPI** — 활성 사용자·대화 수·질의 수·1인당 평균·상위 10명 점유율, 전월 대비 증감
- **핵심 요약** — 경영진 보고에 그대로 쓸 수 있는 문장 5~6줄
- **사용 추이** — 일별 추이(호버 툴팁), 최근 6개월 월별 추이
- **시간대 분석** — 요일 × 시간대 히트맵, 시간대별 질의 (모두 KST 기준)
- **질의 카테고리** — 번역 / 이메일·윤문 / 문서·보고서 / 엑셀·데이터 / 리서치 / 생산·품질 /
  원가·협상 / 무역·물류 / 경영지원 / IT·AI활용 / 이미지·디자인 / 일반·개인 / 예약·자동작업
- **상위 사용자** — 질의 수 막대, 사용자 × 카테고리 히트맵
- **개인 목적 사용 진단** — 개인 질의 비중, 50%/30% 초과 인원 수, 상위 5명 집중도, 근무시간 발생 비율
- **모델·도구·기능 채택** — 모델별 사용량, 도구(검색·코드·이미지), 맞춤 GPT·프로젝트·첨부
- **보안 점검** — 전화번호·주민번호·카드번호·비밀번호 패턴 **건수와 인원만**, 외부 도메인 관리자 로그인,
  스크립트 로그인, 로그인 실패
- **질의어 샘플** — 상위 사용자별 10건, 개인 생활 카테고리 제외·개인정보 마스킹 (접힌 상태)

### 분석 규칙

- 시각은 UTC 로 기록된 로그를 **KST(+9)** 로 바꿔 집계합니다.
- `author.type == user` 인 텍스트 메시지만 "질의"로 셉니다. (어시스턴트 응답 제외)
- 같은 사람이 **같은 프롬프트를 10회 이상, 서로 다른 5일 이상**에 걸쳐 보냈다면 예약·자동작업으로 보고
  사용자 통계에서 분리합니다.
- 카테고리는 **대화 단위로 주된 작업 1개**를 판정해 그 대화의 모든 질의에 적용합니다.

> **카테고리 분류는 키워드 규칙 기반이라 정확도가 60~70% 수준입니다.**
> 분기·반기 보고처럼 정확도가 중요하면 Claude 에 로그 파일을 주고
> `chatgpt-usage-log-report` 스킬로 LLM 재분류를 요청하세요. 엑셀·1장 PDF·보고 메일 초안까지 만들어 줍니다.

## 4. 설정 (`settings.json`)

| 키 | 기본값 | 설명 |
|---|---|---|
| `downloadBat` | `대화내용_받기.BAT` | 실행할 받기 파일 이름 |
| `downloadTimeoutMinutes` | `120` | 이 시간을 넘기면 받기를 중단하고 실패 처리 |
| `taskTime` | `09:00` | 스케줄러가 매일 확인하는 시각 |
| `taskName` | `ChatGPT-Monthly-Log-Report` | 작업 스케줄러에 표시되는 이름 |
| `reportDir` / `logDir` / `stateDir` | `reports` / `logs` / `.state` | 결과·로그·상태 폴더 |
| `pythonExe` | (비움) | 자동 인식이 안 될 때 `python.exe` 전체 경로 |
| `keepLogDays` | `365` | 이보다 오래된 로그 파일은 자동 정리 |

시각을 바꿨다면 `월간자동화-설치.bat` 을 다시 한 번 실행해 스케줄을 갱신하세요.

## 5. 잘 안 될 때

먼저 `logs\run_*.log` 의 마지막 줄을 보세요. 종료 코드가 원인을 알려 줍니다.

| 코드 | 뜻 | 조치 |
|---|---|---|
| 0 | 정상 | — |
| 2 | 받기 파일 없음 | `settings.json` 의 `downloadBat` 이름·위치 확인 |
| 3 | 파이썬 없음 | 파이썬 설치 또는 `pythonExe` 지정 |
| 4 | 분석할 로그 파일 없음 | `logs\download_*.log` 에서 받기 실패 원인 확인 (토큰 만료 등) |
| 5 | 파일은 있는데 읽어낸 레코드가 0 | 파일 형식 확인 후 Claude 에 문의 |
| 6 | 받기 시간 초과 | `downloadTimeoutMinutes` 를 늘리기 |
| 7 | 분석 스크립트 없음 | `scripts\analyze_logs.py` 가 있는지 확인 |

- 작업이 등록됐는지 보려면: **작업 스케줄러 → 작업 스케줄러 라이브러리** 에서 `ChatGPT-Monthly-Log-Report`
- 이 작업은 **로그인한 사용자 계정**으로 돌아갑니다. PC 가 꺼져 있으면 실행되지 않고, 대신 다음 실행 때 보충합니다.
- 받기 BAT 가 토큰·비밀번호를 물어보는 대화형이면 자동 실행이 멈춥니다. 이때는 BAT 안에서
  토큰을 환경변수나 파일로 읽도록 바꿔야 합니다.

## 6. 개인정보 주의

이 폴더에는 **직원들의 실제 대화 내용**이 들어옵니다.

- 리포트와 로그 파일은 저장소에 올라가지 않도록 `.gitignore` 로 막아 두었습니다.
- 리포트에는 사용자 아이디 앞 2자만 표시하고, 질의어의 연락처·이메일·카드번호·주민번호는 마스킹합니다.
- 그래도 **질의어 원문 일부가 포함**되므로, 경영진 배포용이 필요하면 원문 없는 버전을 따로 만들어 쓰세요.
- 웹에 올리지 말고 파일로만 전달하는 것을 권장합니다.
