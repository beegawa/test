# 매일 뉴스 클리핑 메일 (n8n 워크플로우)

매일 오전 7시에 뉴스를 수집해 카테고리별로 정리한 뒤 HTML 메일로 발송합니다.

- **수집 분야**: 주요뉴스 · 경제 · IT·기술 · AI (구글뉴스 한국판 RSS)
- **발송**: Gmail SMTP (앱 비밀번호)
- **중복 제거 / 최근 24시간 필터 / 카테고리당 최대 8건**

## ⚠️ 먼저 알아둘 점

이 워크플로우는 **본인 PC에 설치한 n8n에서 실행**해야 합니다.
Claude 작업 환경(원격 컨테이너)에서 돌린 n8n은 네트워크 정책상
외부 뉴스 사이트(403 차단)와 SMTP 포트(587/465 차단)에 접근할 수 없고,
`localhost:5678` 도 그 컨테이너 내부 주소라 본인 브라우저에서는 열리지 않습니다.

## 설치

### Windows
```powershell
powershell -ExecutionPolicy Bypass -File install-windows.ps1
n8n start
```

### macOS / Linux
```bash
./install-unix.sh
set -a; source ~/n8n/.env; set +a
n8n start
```

스크립트가 하는 일: Node.js 확인·설치 → n8n 전역 설치 → `~/n8n` 에 설정 생성 → 워크플로우 등록.

설치 후 브라우저에서 **http://localhost:5678** 접속 → 소유자 계정을 만들면
`매일 뉴스 클리핑 메일` 워크플로우가 이미 들어와 있습니다.

## 발송 설정 (3단계)

### 1. Gmail 앱 비밀번호 발급
1. Google 계정 → 보안 → **2단계 인증**을 켭니다 (필수).
2. https://myaccount.google.com/apppasswords 에서 앱 비밀번호를 만듭니다.
3. 생성된 16자리를 복사합니다 (공백 없이 입력).

### 2. n8n 에 SMTP 자격증명 등록
n8n 화면 좌측 **Credentials → Add credential → SMTP** 에서:

| 항목 | 값 |
|---|---|
| Host | `smtp.gmail.com` |
| Port | `587` |
| User | 본인 Gmail 주소 |
| Password | 위에서 만든 앱 비밀번호 |
| SSL/TLS | 끔 (STARTTLS 사용) |

저장 후 **메일 발송** 노드를 열어 이 자격증명을 선택합니다.

### 3. 주소 입력
**설정** 노드에서 두 값을 채웁니다.

| 항목 | 설명 |
|---|---|
| `받는사람` | 클리핑을 받을 메일 주소 |
| `보내는사람` | 위 Gmail 주소와 **동일해야 합니다** (다르면 Gmail이 거부) |

## 실행

- **테스트**: 워크플로우 화면에서 `Execute workflow` → 메일 수신 확인
- **자동 실행**: 우측 상단 **Active** 토글을 켜면 매일 오전 7시에 발송됩니다
  (n8n 프로세스가 켜져 있어야 합니다)

## 커스터마이징

| 바꾸고 싶은 것 | 위치 |
|---|---|
| 발송 시각 | `매일 07시 실행` 노드의 Trigger Hour |
| 수집 분야 추가/삭제 | `뉴스 소스 목록` 노드의 `소스` 배열 |
| 수집 기간 (기본 24시간) | `설정` 노드의 `수집시간_시간` |
| 카테고리당 건수 (기본 8건) | `설정` 노드의 `카테고리당_최대건수` |
| 메일 디자인 | `메일 본문 생성` 노드 |

특정 키워드만 모으려면 `뉴스 소스 목록` 에 아래 형태로 추가합니다.

```js
{ 카테고리: '자사', url: 'https://news.google.com/rss/search?q=' + encodeURIComponent('신원') + '&hl=ko&gl=KR&ceid=KR:ko' },
```

새 카테고리를 추가했다면 `기사 정리` 노드의 `순서` 배열과
`메일 본문 생성` 노드의 `색` 객체에도 같은 이름을 넣어주세요.

## 워크플로우 구조

```
매일 07시 실행 → 설정 → 뉴스 소스 목록 → RSS 수집 → 기사 정리 → 기사가 있으면
                                                                    ├─ 있음 → 메일 본문 생성 → 메일 발송
                                                                    └─ 없음 → 기사 없음 (발송 생략)
```

- `RSS 수집` 은 실패해도 멈추지 않고(3회 재시도 후 통과) 나머지 소스를 계속 처리합니다.
- 수집 결과가 0건이면 빈 메일을 보내지 않습니다.

## 로직 검증

Code 노드 3종을 n8n 실행 환경을 모사한 하네스로 검증합니다 (네트워크 불필요).

```bash
node test/run-codenodes.js
```

검증 항목: 24시간 필터 · 링크 중복 제거 · HTML 태그/엔티티 정리 ·
제목에서 언론사 분리 · 최신순 정렬 · 건수 제한 · 발행일 없는 기사 통과 ·
빈 입력 처리 · 메일 본문에 undefined/NaN 누출 없음.

`test/preview.html` 로 메일 디자인을 브라우저에서 미리 볼 수 있습니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| `Invalid login: 535` | 앱 비밀번호가 맞는지, 일반 계정 비밀번호를 넣지 않았는지 |
| 메일이 안 옴 | `보내는사람` 이 SMTP User 와 같은 주소인지 |
| 기사가 0건 | `수집시간_시간` 을 48 정도로 늘려보기 |
| 자동 실행 안 됨 | 워크플로우 `Active` 토글, n8n 프로세스 실행 여부 |
